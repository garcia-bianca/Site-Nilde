## 🎯 Princípios de Design Aplicados

- Títulos grandes e em fonte serifada
- Subtítulos em peso mais leve
- Espaçamento generoso entre seções

### Consistência
- Bordas arredondadas de 12px em cards
- Sombras com mesma direção e intensidade
- Mesma paleta em todos os elementos

### Contraste
- Texto escuro sobre fundo claro
- Botões Rose Gold sobre fundos neutros
- Hover states com mudança de cor

### Espaçamento
- Padding generoso em seções (6rem)
- Gap consistente em grids (2.5rem)
- Margens equilibradas entre elementos

## 🎯 Como Usar

### 1. Clonar o Repositório

```bash
git clone [https://github.com/garcia-bianca/salao-nilde-oliveira.git](https://github.com/garcia-bianca/salao-nilde-oliveira.git)
```

### 2. Abrir no Navegador

Abra o arquivo `index.html` no seu navegador preferido.

### 3. Personalizar

#### Alterar Cores
Edite as variáveis CSS no `<style>`:

```css
:root {
  --cor-primaria: #B76E79;      /* Sua cor principal */
  --cor-secundaria: #F7E7CE;    /* Sua cor secundária */
}
```

#### Alterar Fontes
Substitua no `<head>`:

```html
<link href="[https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@400;500;600;700&family=Montserrat:wght@300;400;500;600&display=swap](https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@400;500;600;700&family=Montserrat:wght@300;400;500;600&display=swap)" rel="stylesheet">
```

#### Alterar Telefone do WhatsApp
Procure por `https://wa.me/558888588494` e substitua pelo seu número.

#### Alterar Imagens
Substitua as URLs do Unsplash pelas fotos reais do salão.

## 💡 Destaques Técnicos

### Performance
- **Sem dependências externas** (apenas Google Fonts)
- **CSS inline** (sem requisições adicionais)
- **SVG inline** (ícones leves e escaláveis)
- **Lazy loading** natural (imagens carregam conforme scroll)

### Acessibilidade
- **HTML semântico** (header, nav, section, footer)
- **Alt text** em todas as imagens
- **Contraste adequado** entre texto e fundo
- **Focus states** em elementos interativos

### SEO
- **Meta description** otimizada
- **Títulos hierárquicos** (h1, h2, h3)
- **Links internos** com âncoras
- **Schema markup** (pode ser adicionado)
